**Интересные тестовые задания от Яндекса**
===

*Первая задача.*

В офисе AtCoder есть один увлажнитель. В момент времени 0 в нем нет воды. Вы доливаете воду N раз. В i-й раз (1 ≤ i ≤ N) вы доливаете V_i литров в момент T_i.
Гарантируется, что T_i < T_{i+1} для всех 1 ≤ i ≤ N−1.
Увлажнитель протекает: пока в нем есть вода, её количество уменьшается со скоростью 1 литр за единицу времени.
Требуется найти количество воды в увлажнителе сразу после того, как вы закончите долив в момент T_N.

Данные подаются как многострочная строка (input_str):

Первая строка: одно целое число N — количество доливов.
Следующие N строк: по два целых числа T_i и V_i, разделённые пробелом.
Гарантируется, что T_i строго возрастают.
Функция должна вернуть строку с одним числом — количеством воды сразу после долива в момент T_N.

*Комментарий*

Сложность O(n)

Изначально планировал сделать через списки, но тогда возникла проблема разной размерности всего списка временных единиц и списка "долива". 
Инициализировать нулевой (или единичный) массив, туда на позицию добавить V и сделать другой сразу отсортированный размерностью до последнего времени показалось слишком затратным.
Поэтому нашлось более изящное решение в виде отслеживания временного интервала, а за счет того, что уменьшается всегда на 1, не потребовалось никаких других операций
